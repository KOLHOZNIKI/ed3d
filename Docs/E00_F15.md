# E00 F15 nearby-surface isolation

The source FBX contains two disconnected rectangular panels with overlapping screen and projection footprints. The panels lie 7.8125 mm apart. Panel A uses a warm checker and panel B a cool stripe pattern. Each pattern has its own authored PNG. The fixture packs them into one linked Base Color atlas so both panels share a mesh and material. The target FBX moves both panels and extends panel A's right edge. The inputs and their deterministic generator are project-owned under the repository's MIT license. [Source ZIP](../tools/e00/fixtures/f15_source.zip) · [Target ZIP](../tools/e00/fixtures/f15_target.zip) · [Generator](../tools/e00/f15-fixture.mjs)

## Brush

The 24-viewport-pixel brush follows the original FBX control-point topology. At the first visible hit of the stroke center, it locks to the hit triangle's edge-connected component. The worker retains the depth test and uses the same component across UV chart seams. The probe drags on panel A about 6 mm from its right edge, where the footprint also covers a visible part of panel B. Its control gives both panels the same component ID while retaining the depth test, camera, radius and atlas.

| Exported Base Color versus unpainted bake | Changed texels on A | Changed texels on B |
| --- | ---: | ---: |
| Component lock | 64,165 | 0 |
| Control with one component ID | 64,525 | 45,698 |

The probe sampled the interiors of all four exported UV triangles, covering 1,133,600 texels on A and 1,150,240 on B. It also compared the positions and primary UVs of the brush exports against the unpainted bake.

## Projection bake

The projection prototype takes an explicit eligible source list per target component. It casts a ray along the interpolated target normal, searches the eligible components' bounding-volume trees, and samples the closest source hit up to 20 mm away with a normal deviation of at most 60°. The exported PNG marks misses in opaque magenta and the manifest records the count. In the overlapping area, panel B is 3.90625 mm from target A while source A is 11.71875 mm away. The control makes both source panels eligible for both targets.

| Exported Base Color | A checker texels on target A | B stripe texels on target A | Miss texels on target A | B stripe texels on target B |
| --- | ---: | ---: | ---: | ---: |
| Explicit source selection | 1,133,600 | 0 | 118,560 | 1,150,240 |
| Control with both sources eligible | 1,015,040 | 237,120 | 0 | 1,150,240 |

With source selection, target B had zero checker texels and zero misses. Every miss on target A lay on the extension beyond the eligible source panel, and the miss count matched the manifest. All 1,918,654 samples away from source pattern transitions matched the expected RGB exactly. The probe reopened the projected ZIP in the application. ufbx 0.23.0 independently matched all eight control points, four triangle boundaries, original corner UVs and corner normals for each of the painted and projected ZIPs against its respective input. Both exports had four valid atlas triangles and one linked texture.

F15 covers the disconnected static panels for §13.2 and §14.4 and demonstrates AT-14 isolation and visible misses on this fixture. The current brush still uses a screen-space footprint within the selected component. The two-sheet case leaves geodesic limits on folded connected surfaces to E03. The projection probe uses the E00 worker and FBX ZIP exporter with a single opaque Base Color material. E08 owns the full projection workflow and its source-selection UI. ## Reproduce on Windows

```powershell
npm.cmd ci
npm.cmd install --prefix test-results/e00-browser --save-exact playwright-core@1.65.1
$chrome = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
node tools/e00/f15-browser.mjs $chrome
```

Chrome 158.0.8127.37 completed the probe with no external requests. The pinned fixture SHA-256 hashes are `eb5b80e725d196d838bffaf50a3105edb51f094bcbf206dfc048a426db800a96` for the source and `3b1323b4ed75d8804f4baae6d066833bdd234ceb8726f60898e97a71e16ac3fa` for the target. `node tools/e00/f15-fixture.mjs` regenerates both archives under `test-results/e00/f15/`. The browser writes `browser-report.json`, `f15_source_e00_baked.zip`, `f15_source_e00_painted.zip`, `f15_target_e00_baked.zip` and two unrestricted control ZIPs to the same directory.

For the ufbx check, extract the input and output ZIPs separately. Run `inspect_fbx <input.fbx> <output.fbx> --baked <output/uv-atlas-source-corners.bin>` for the source and painted pair and for the target and projected pair.
