# E06 UV editing and direct bake

E06 implements the UV Editor and the direct surface correspondence workflow in specification §§11 and 14. UV selections and edited coordinates resolve to source mesh corners. Adjacent corners share a UV vertex only across a continuous, uncut edge. Overlaps, out-of-tile coordinates, mirrored winding, and degenerate triangles are reported when a layout opens.

The editor supports numeric and pointer transforms, alignment, snapping, seam marking, planar projection, and packing with configurable size, pixel spacing, rotation, and relative or equalized density. Whole-mesh unwrap and selected-face unwrap use the local xatlas worker. The adapter verifies every output index against xatlas `xref`. It retries with separate charts when texel coverage or positive-area triangle intersection reveals a conflict.

**Change Mapping** commits UVs with the existing image bytes. **Preserve Appearance** defaults to the current working revision, including paint, and can use the original import while its geometry still matches. It rasterizes the new UVs and samples the source maps through triangle-corner correspondence. Color filters operate in linear light. Numeric maps and alpha are filtered as data. Normal transfer uses source and target MikkTSpace frames in the base pose. Pixels outside the coverage mask receive the nearest chart edge color to reduce dark gutters under mip filtering. The coverage mask distinguishes sampled texels from explicitly accepted neutral repair texels.

Each completed transfer is one undoable revision. The app checks the revision immediately before committing the new UVs and map bindings. Cancellation and conflicting target UVs leave the working revision unchanged. Project schema 6 saves applied UV edits, map resources, coverage, and source labels. The reader retains support for schemas 1–5.

The private Tripo fixtures are the same local exports used in E00 and are excluded from Git. The GLB squares are generated by the browser probe. The directional FBX is generated by the E00 normal fixture script from synthetic geometry and textures.

## Reproduce

Use the local Playwright setup from the E00 report, Python with Pillow, and the Tripo fixture directory. Generate the directional input if its E00 output is absent.

```powershell
npm.cmd run build
node tools/e00/normal-fixture.mjs
node tools/e06-browser.mjs 'C:/Program Files/Google/Chrome/Application/chrome.exe' 'D:/downloads/Tripo'
python tools/e06-verify.py --unity 2022.3.62f2 --tripo 'D:/downloads/Tripo'
```

Run Unity with `-batchmode -force-d3d11 -quit -executeMethod E06Probe.Run` and use the generated project directory as its working directory and `-projectPath`. The result directory under `test-results/e06` contains the ZIP and GLB exports, browser and independent parser results, and Unity captures. Use `tools/e00/inspect_fbx.c` with `--baked` and each export's `uv-atlas-source-corners.bin` to compare raw FBX inputs to their exports.

## Supported scope

- UV edits and unwrap run per object. Preserve Appearance uses one material on the selected mesh. FBX Preserve Appearance uses one mesh in the whole asset and needs room for an additional UV layer. FBX ZIP export promotes the bake atlas to UV0 and preserves the original channels. Shared atlases and cross-object texture transfer belong to later stages.
- GLB transfers linked Base Color, Normal, Emissive, AO and a shared packed metallic–roughness map. FBX transfers Base Color, Normal, and the recognized Tripo data maps. Transparent FBX requires the explicit E00 alpha profile. The normal transfer rejects authored tangents, normal-map transforms or sampling outside the source tile. FBX export still blocks morph targets.
- The xatlas wrapper supports manual seams that partition the selected faces. Non-partitioning marked cuts require a longer seam or manual projection. The packing tool reports when one atlas cannot fit. Stitch, Relax and pin constraints are V1+.
- Direct transfer can use neutral data for repair faces and records those texels in the coverage mask. Spatial projection onto modified surfaces and constrained source matching follow in E08. E07 is static extraction.
