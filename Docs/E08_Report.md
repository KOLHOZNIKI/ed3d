# E08 extended repair and spatial projection

Smooth Fill refines the triangulated contour, keeps original boundary edges and points fixed, and fairs the new vertices using their topological neighbors. Grid Fill builds a Coons patch from four sides and keeps the resulting quads in FBX. Bridge connects two loops or two selected equal-length spans. Its default pairing minimizes distance, and the preview accepts explicit starts, traversal order, twist, and segment count. Patch validation checks winding, area, boundary attachment, self-intersections, and intersections against the source mesh. New skinned points interpolate and normalize their boundary influences.

Spatial Projection first uses exact correspondence on unchanged source triangles of the same mesh. Other points use a BVH over the explicitly eligible source component. Angle, ray direction, offset, and distance constrain the search. Unassigned repair faces are excluded from a working source. The miss policy is an empty Base Color texel, a selected fill color, or an explicitly permitted nearest point within the eligible component and its distance and angle limits. Target material factors and vertex colors remain material and geometry properties.

Normal transfer samples the source tangent-space vector and casts it into the target MikkTSpace frame. The source and target normal matrices handle nonuniform transforms. The operation rejects invalid sampled bases and normals below the target tangent plane. Each transfer produces coverage and commits UVs, maps, and bindings in one revision. Schema 8 preserves projection diagnostics. FBX exports include the projection record and any projected auxiliary maps in the ZIP manifest.

## Reproduce

```powershell
npm.cmd run build
node tools/e08-fixture.mjs
node tools/e08-browser.mjs 'C:/Program Files/Google/Chrome/Application/chrome.exe'
python tools/e08-verify.py --unity 2022.3.62f2
```

The optional browser modes `tripo` and `skin` use the local plate and E00 repair export or the E05 skinned fixture. Add `--tripo 'D:/downloads/Tripo'` when preparing Unity for the plate. Run Unity with `-batchmode -nographics -quit -executeMethod E08Probe.Run` in the generated project directory. Compile `tools/e08-fbx.c` with the pinned E00 ufbx. The native check accepts the synthetic source, Grid, Smooth and projected FBX files, with `--plate` and `--skin` for the other cases. Reports and exports are under `test-results/e08`.

## Scope

- The new repair methods work on supported simple contours. Bridge accepts closed loops and matched spans selected from them. Smooth keeps the rim pinned. Grid requires compatible opposite sides.
- Spatial projection uses one static source mesh and one static target mesh in the same document, with one material each and a linked Base Color. The projection size limit is 2048 pixels. FBX projection uses UV0 and requires the global atlas to be cleared. The normal workflow uses generated tangents and identity normal-map sampling.
- Unresolved texels remain visible in the coverage mask and can be painted with the existing texture tools. An empty Base Color texel carries zero alpha. The target material's alpha mode governs display and export.
