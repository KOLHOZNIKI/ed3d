# E07 static asset extraction

AssetFixer 0.2.0 adds the Extract workflow from specification §15. The preview isolates selected faces without changing document visibility. Selection can cover the whole mesh, groups of edge-connected components, or arbitrary faces. The tool reports open source edges and edges exposed by the selection. Choose Separate Geometry and use Repair on the result before making an independent copy when a cut needs a cap.

Copy leaves the original mesh intact. Cut requires an explicit choice and keeps at least one face on the source. The independent workflow transfers the current working maps to new material bindings and removes unrelated geometry and texture files from standalone exports. The copied mesh, UV changes, maps, and pivot commit as one undoable revision. Project schema 7 saves independent map ownership and export settings.

Keep UVs samples the occupied region and clears unused texels beyond the requested padding. Pack uses the original islands. Auto Unwrap creates new charts in the xatlas worker. Each used material receives its own map set. Batch candidates can be renamed, previewed, grouped, and excluded. The tool prepares atlases sequentially and writes a ZIP containing only the chosen assets and a manifest.

Original, bounds center, bottom center, and a picked or entered local point are available as pivots. Moving the pivot alone preserves world-space vertex positions. The standalone export can place the pivot at world zero independently of project placement. Explicit rotation is in local axes and scale is uniform.

## Reproduce

```powershell
npm.cmd run build
node tools/e07-fixture.mjs
node tools/e07-browser.mjs 'C:/Program Files/Google/Chrome/Application/chrome.exe'
python tools/e07-verify.py --unity 2022.3.62f2
```

Run Unity with `-batchmode -nographics -quit -executeMethod E07Probe.Run`, using the generated directory as `-projectPath` and the working directory. Compile `tools/e07-fbx.c` with the pinned ufbx used in E00 and pass `batch.fbx`, `Assembly.fbx`, and `Rebased.fbx`. Reports and the generated fixtures are in `test-results/e07`.

## Scope

- Each group selects faces from a single source mesh. A project can export independent objects from multiple source meshes in the same batch. Scoped exports use the source format. Static extraction blocks skinned, morphed, and object-animated meshes.
- Keep UVs requires nonoverlapping target triangles inside 0–1. Repack or Auto Unwrap can prepare a new tile for other layouts. The transfer inherits the E06 restrictions on supported maps and normal sampling. FBX assets with an active legacy global bake need the global atlas discarded before extraction.
- Boundary repair runs separately. Repair faces without source pixels can be filled with neutral values and painted afterward. Spatial transfer and its source matching follow in E08.
