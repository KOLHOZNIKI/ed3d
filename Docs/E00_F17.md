# E00 F17 compressed GLB from Meshy

F17 uses `pawn-lo.glb` from the Gambit scene in Dioramas. The publisher generated the geometry with Meshy 7.1 via fal and published the optimized GLB with glTF Transform 4.5.1. AssetFixer tests the published bytes and stores them as `meshy-gambit-pawn-lo.glb`. Credit **Dioramas (github.com/blendi-remade/dioramas)** under CC BY 4.0. [Original model](https://github.com/blendi-remade/dioramas/blob/868539fb5b64a843071a2247d5d8bacb706a07b1/public/models/gambit/pawn-lo.glb) · [Fixture and attribution](../tools/e00/fixtures/meshy-gambit-pawn-lo.LICENSE.md)

## Input extensions and local support

The input declares all three extensions in both `extensionsUsed` and `extensionsRequired`.

| Extension | Use in the published fixture | Export |
| --- | --- | --- |
| `EXT_meshopt_compression` | Four compressed streams for indices, positions, normals and UV0. The second declared buffer is a URI-less placeholder for their decoded data. | Writes the decoded streams without Meshopt compression. |
| `KHR_mesh_quantization` | Positions and normals use normalized signed 16-bit values. UV0 uses normalized unsigned 16-bit values. The mesh node stores the position scale and translation. | Retains the same quantized components and node transform. |
| `EXT_texture_webp` | Three embedded 1024 × 1024 WebP images for Base Color, Normal, and packed Metallic/Roughness. | Retains the required extension and the original image bytes and bindings. |

The production bundle uses the Meshopt WebAssembly decoder shipped with Three.js r187 and Chrome's local WebP decoding. The adapter accepts one embedded binary buffer and, for required Meshopt input, one optional URI-less placeholder buffer. It checks compressed ranges, layout and a 160 MiB decoded-size budget before decoding. The WebP path covers required embedded WebP sources. Optional alternate fallback images remain outside this profile. The exporter retains quantized normals at their authored precision because `KHR_mesh_quantization` allows non-unit lengths before lighting normalization. [Meshopt extension](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Vendor/EXT_meshopt_compression/README.md) · [Quantization extension](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_mesh_quantization/README.md) · [WebP extension](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Vendor/EXT_texture_webp/README.md)

## Results

Chrome 158.0.8127.37 loaded the production build from localhost. Playwright then set the browser context offline and blocked HTTP and HTTPS requests before selecting the file. Import, rendering, the GLB download, and reopening the exported file completed with zero network requests during the offline phase. The malformed-offset control was rejected before decoding, and the prior model's export control stayed enabled.

Independent glTF Transform 4.5.1 `NodeIO` with Meshoptimizer 1.1.1 decoded the source and compared it with the exported GLB. All 19,274 positions, normals and UVs matched exactly, including component types and normalization flags. All 84,207 indices (28,069 triangles) matched in order. The mesh node's world matrix, material settings, UV channels, and texture sampling settings matched. All three WebP payloads had identical SHA-256 values. The fixture is a static mesh with zero skins and zero animations. [Independent parser configuration](../tools/e00/inspect_f17.mjs) · [NodeIO and Meshopt integration](https://gltf-transform.dev/modules/extensions/classes/EXTMeshoptCompression)

Khronos glTF Validator `2.0.0-dev.3.10` reported zero errors and the same single warning for generated tangent space in the input and export. Its input report also lists an informational message for the Meshopt extension. The data comparison comes from the independent reader above.

## Reproduce on Windows

```powershell
$chrome = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
$source = 'tools/e00/fixtures/meshy-gambit-pawn-lo.glb'
$exported = 'test-results/e00/f17/meshy-gambit-pawn-lo_e00.glb'
npm.cmd ci
npm.cmd install --prefix test-results/e00-browser --save-exact playwright-core@1.65.1
npm.cmd install --prefix test-results/e00-gltf-transform --save-exact '@gltf-transform/core@4.5.1' '@gltf-transform/extensions@4.5.1' meshoptimizer@1.1.1
npm.cmd install --prefix test-results/e00-glb-validator --save-exact gltf-validator@2.0.0-dev.3.10
npm.cmd run build
node tools/e00/f17-browser.mjs $chrome
node tools/e00/inspect_f17.mjs $source $exported
node tools/e00/validate-glb.mjs $source $exported
```

`test-results/e00/f17/` contains the reference export and the browser, independent reader and validator reports. The CC BY 4.0 attribution for the derived export is recorded above. The export changes the container and geometry compression as described in the results.
